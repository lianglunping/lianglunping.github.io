只适用于 SNP 候选的人工复核。网页仅验证 AS_REF / AS_ALT 的 3′ 末端是否与各自等位一致，并展示你手工指定的 −2 替换后序列；不声明该人为错配能提高 KASP 聚类，也不自动用于订购导出。
长度、Tm 与结构筛查
结构指标单位为连续碱基数，只检查无间隙互补；不计算 ΔG，不代表完整热力学评价。
Tm 计算条件
SantaLucia 1998 最近邻参数；熵盐校正 + 钠当量近似。非自互补时使用 C/4。这里的浓度是计算假设，不是 KASP 试剂盒实测组成。
局部 GC / 复杂度诊断
只用于风险提示和排序说明，不作为实验成功/失败阈值。网页同时报告目标 ±50、±100、±250、±500 bp 的实际 GC。
Auto-rescue · 自动扩大搜索
Sanger 通过扩大 F/R 可搜索范围寻找更远的结合区；KASP 的 AS 引物仍锚定变异，仅 COMMON 可因更大产物范围而远移。不会自动放宽 Tm、GC、结构或 repeat 硬排除条件。坐标模式下若使用“局部模板手工排除区间”，Auto-rescue 会停用，避免窗口改变后误解释这些局部坐标。
参考内近似匹配设置
不允许 gap；不要求 3′ 完全匹配，逐条列出末端错配。仅点击候选上的扫描按钮后运行，不自动把命中数转换成通过标记。
本机热力学计算条件
仅本机 Primer3 模式使用；不是 PCR 退火温度。KASP 保留原候选，并附上含尾序的热力学复核值，不自动批准。

参考、算法与结果边界

v1.1.0-rc4.3

MSU7 与参考序列

默认参考身份为日本晴 Os-Nipponbare-Reference-IRGSP-1.0，注释版本为 MSU / RGAP Release 7。请从官方页面取得基因组 FASTA；不以 CDS、转录本或其他品种序列替代。文件在本机选择，页面本身不包含全基因组。

坐标与序列校验

输入使用 VCF 的 POS / REF / ALT，POS 为 1-based；程序内部区间为 0-based、左闭右开。REF 不匹配时停止该位点。此版本不实现 liftOver、不自动左对齐。若用户加载配套 MSU/RGAP7 GFF3，可按 LOC_Os / 转录本 ID 导航并显示重叠注释；GFF3 坐标映射单独审计。

一代测序模式

候选是扩增目标区域的 PCR 引物，可作为后续测序引物评估的起点。两侧都留出设定的 3′ 端间隔；产物范围在 REF 与 ALT 上分别检查。未自动设计独立内部测序引物，也不处理 AB1 峰图。

KASP 候选模式

分别构建 REF / ALT 单倍型，比较正向与反向候选，输出 AS_REF、AS_ALT 与 COMMON。支持 SNP 及去除公共前后缀后 ≤30 bp 的纯 InDel 初筛。InDel 始终标记需专家复核；不做人工额外错配设计。

特异性检查的范围

结果卡提供零错配和 0–2 处替换扫描；若载入重复注释，同时计算引物与 repeat 的重叠及目标 ±500 bp repeat fraction，按双链完整结合区寻找命中；配对产物范围 40–3000 bp。尾序不搜索，不支持 gap。含模糊碱基窗口保留未判定；位置截断时产物计数只是下界，不能声称无脱靶。

可追溯，不夸大

完整 JSON 含输入窗口、SHA-256、参考元数据、参数、排除区间、候选与扫描状态，可重新载入复核。有限替换匹配不覆盖 gap；未提供的背景变异或 repeat 注释仍属未知；局部 GC / repeat 指标属于描述性风险诊断；Auto-rescue 只扩大允许的产物/COMMON 搜索范围，不放宽 Tm、GC、结构或 repeat 硬排除；实验验证未完成。

MSU GFF3 与剪接序列导航

v1.1.0-rc4.3 可增量解析 gene / mRNA / transcript / exon / CDS / UTR 特征，按 LOC_Os 或转录本 ID 搜索并绘制结构；当前位点还可叠加到 transcript 结构上，并报告 exon/CDS/UTR/intron genomic overlap 与最近 junction boundary 距离。这里的 donor/acceptor 按转录方向标记外显子边界；v1.1.0-rc4.3 还会从当前 FASTA 读取边界附近二核苷酸，在 transcript 方向检查 donor=GT / acceptor=AG，并报告变异是否直接覆盖该 2 bp motif。该检查仍不等价于剪接后果或功能注释。GFF3 不用于猜测 REF/ALT。

v1.1.0-rc4.3 KASP 3′ 审计

对 SNP 候选独立核对 AS_REF 与 AS_ALT 的 3′ 末端是否分别锚定对应等位，并允许用户手工预览 −2 位替换后的序列。该预览不进入候选排名、QC 复核资格或订购导出，也不自动推荐“最佳人为错配”。InDel 仍维持专家复核状态。

候选版审计清单

v1.1.0-rc4.3 可导出独立 audit manifest JSON，记录当前 QC 规则、参考/GFF 元数据、逐位点裁决、KASP 3′ 锚定与未完成检查。该清单用于复核与复现，不等价于湿实验 validation。

候选裁决与排序

v1.1.0-rc4.3 新增逐位点可解释排序。排序只使用已观察的 repeat、3′ repeat、参考内命中、InDel KASP 专家复核标记与原候选分数；未运行的检查记为“证据缺口”，不会被当成通过。标签“推荐”仅表示优先进入人工复核，不表示可直接订购或实验成功。
