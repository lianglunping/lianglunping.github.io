开始使用

先运行固定种子的合成 SNP / InDel 示例。使用真实位点时，在电脑浏览器选择本地未压缩 MSU FASTA 与配套 FAI，或构建索引。按需加载 GFF3、重复注释及已筛选的背景变异。输入 1-based POS 和真实 REF/ALT；REF 不一致时不产生该位点的候选。

重复与 GC

重复注释支持仅标注或结合区硬排除；重复区间先取并集。区域 GC、50 bp 峰值、复杂度与读序距离属于可解释风险信息，不是成功率模型。Auto-rescue 扩大产物搜索范围，不放宽引物筛查阈值。

序列与数据边界

脚本和页面来自同一个站点，不使用第三方 CDN、分析追踪、Service Worker 或自动持久保存。输入文件在浏览器读取。设计、索引、摘要和参考扫描在本机计算。应用没有上传 API，公开站点禁用本机 Primer3 选项。

页面自身及源代码加载会产生托管平台访问请求和日志；并非完全无网络。CSP 限制应用连接；脚本带内容完整性摘要。它们不能防范恶意托管者、未来改版或浏览器扩展。输入和导出的 JSON/CSV 可能包含样本信息及局部序列，请不要提交到公开仓库或 issue。

结果与局限

0–2 处替换扫描不允许 gap；没有提供的背景和重复注释仍属未知。剪接 motif 是参考序列与改变区间关系，不预测 RNA 后果。KASP InDel 需专家复核；人为 −2 错配仅预览，不改写订购草稿。程序不分析 AB1，不自动设计独立内部测序引物。

完整真实 MSU FASTA 端到端、Primer3 原生数值和真实 Sanger/KASP 成败回测仍未完成。手机可先看界面和合成小例，不承诺完整水稻基因组的大文件性能。

复现与维护

GitHub 的 rice-primer-studio/ 目录提供本站全部 HTML 与 JavaScript 运行源码。release.json 固定每个运行文件的长度和 SHA-256；运行 JSON 保留版本、发布模式与算法源码摘要。本站不运行 Python 或 Primer3 后台。完整本地开发包另含构建器、测试与可选本机服务，不能将该服务暴露到公网。
