Hermes Local Drive

A personal Google Drive connection for an owner-operated Hermes assistant, using rclone on the owner's computer.

This integration lets the owner ask Hermes to find files, inspect folder listings, download task inputs, and upload or update task results in the owner's Google Drive. It is maintained by lianglunping for personal use. It is not a shared service for other people's Google accounts.

Why Google Drive access is requested

The local client needs access to existing Drive folders and files, including items created outside this integration. Depending on the permission granted, it can read file metadata and contents and create or modify files. A broad Drive permission may make more files technically accessible than a particular task requires; the owner's task instructions define which files and actions are authorized.

How a task is handled

  • The owner authorizes the desktop client through Google's consent screen.
  • Hermes uses the local rclone connection to perform the Drive actions needed for the owner's task.
  • Downloaded files, generated results and task records may remain on the owner's computer until the owner removes them.
  • If the owner explicitly authorizes the specific data and recipient service for cloud-assisted analysis, necessary content may be processed through a verified compatible model API, subject to Google Limited Use requirements.

Google data is handled locally by default. This does not mean that all Hermes tasks are offline. This application does not send Google-derived content to unverified cloud model routes. Authorized cloud processing must use a compatible API; Google user data must not be sent for general-purpose model training.

Read the Privacy Policy for access, storage, sharing, retention and revocation details.

Owner controls

The owner chooses tasks, reviews results, controls local files and may disconnect the application at any time through Google Account connections. This website provides application information; it does not sign visitors in or receive Drive credentials.

Contact

For application or privacy questions, open an issue in the public GitHub repository. Do not post credentials, private file contents or personal contact information in a public issue. The owner can also use the support email shown on Google's consent screen.
