Privacy Policy

This policy covers Hermes Local Drive, the personal desktop Google Drive integration maintained by lianglunping.

The application runs through the owner's local Hermes assistant and rclone client. It serves the owner's authorized tasks and is not a service for collecting other people's Google accounts.

Data accessed and purpose

After Google OAuth authorization, the client may access Drive account information needed to identify the connection, file and folder names, IDs, types, sizes and other metadata, and file contents needed for a task. With a write permission, it may create, upload or update files as instructed. The granted Drive permission can cover existing files across the account; task instructions limit actual use and do not create a technical per-folder OAuth restriction.

The data is used to locate task inputs, transfer files, produce requested analyses or summaries, save results and diagnose connection or task errors. OAuth authorization does not by itself authorize every possible operation. Destructive changes or broader sharing require the owner's authorization for that action.

Local storage and retention

OAuth client configuration and access or refresh tokens are stored in the owner's local client configuration, under local operating-system access controls. They are not included in this public website. Tokens are used only to maintain the authorized connection with Google.

Downloaded files, task outputs, working copies and task records may be stored locally. They remain until the owner deletes them or applies the owner's retention rules; this integration does not promise a fixed automatic deletion period. Local backups may retain copies until the owner removes those backups.

Cloud processing and other recipients

Drive file operations use the local client and Google APIs by default. Only when the owner explicitly authorizes the specific data and recipient service for cloud-assisted processing may the minimum necessary file content, metadata or derived content be sent through a verified compatible model API to produce the requested result. A task submitted through a messaging service may also pass the owner's instructions and selected results through that service.

This application does not send Google-derived content to unverified cloud model routes. Permitted cloud processing must support the requested user-facing task, follow Google Limited Use requirements and use a provider route whose applicable terms and settings have been checked to permit that use. If a compatible route is not established, Google-derived content must remain local. OAuth tokens and client secrets must not be sent in model prompts or public messages.

This policy does not make a universal promise about a provider's retention, human review or regional processing. Those details depend on the actual service, endpoint, contract and settings. The owner must select the applicable processing route before sending Google-derived content. Unnecessary copies and unrelated secondary uses are not authorized.

Limited Use commitment

Hermes Local Drive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This application does not sell Google user data, use it for advertising, or use or transfer it to train general-purpose AI or machine-learning models. These restrictions also apply to aggregated, anonymized and derived Google data. Any permitted transfer is limited to providing the owner's authorized feature, security, legal obligations, or another exception expressly permitted by that policy. Access by another person requires the owner's affirmative authorization for the specific data, except where a policy-permitted security or legal exception applies.

Disconnecting and deleting data

The owner may revoke access through Google Account connections and stop the local integration. Revocation prevents future authorized Google API access but does not delete files already downloaded, local task records or copies already sent to an authorized processor. The owner can remove local credentials and copies and use the relevant provider's controls or contact process to request deletion of remotely retained content.

This public website

These static information pages do not collect Google credentials, connect to Drive, embed a login form or use custom analytics. GitHub Pages hosts the pages and may process normal website request information under GitHub's Privacy Statement.

Contact and changes

For questions, use the public repository's issue tracker without posting private data, or the support email displayed on the Google consent screen. Material changes to data use will be disclosed here and require renewed authorization before the changed use begins.
